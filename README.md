# Chrome Dino RL Agent

## 프로젝트 개요
본 프로젝트는 구글 크롬 브라우저의 오프라인 공룡 게임(Chrome Dinosaur Game)을 자율적으로 플레이하는 심층 강화학습(Deep Reinforcement Learning) 에이전트 체계입니다. DQN(Deep Q-Network), D3QN(Dueling Double DQN) 아키텍쳐의 CNN(Convolutional Neural Network) 구조를 채택하여, 화면의 픽셀 데이터를 실시간으로 넘겨받아 최적의 행동(점프, 숙이기, 대기)을 수행하도록 설계되었습니다.

---

## 주요 기능 및 특징
- **실시간 화면 프레임워크 최적화**: `mss` 및 OpenCV 라이브러리를 활용해 템플릿 매칭 기반으로 단일 게임 영역을 자동 추적 및 캡처합니다. 주·야간의 테마 변동성에 대처하기 위해 Canny Edge Detection 및 프레임 차분(Difference) 전처리를 이용해 시각적 상태(State)를 추출합니다.
- **다양한 버퍼 및 인공신경망 지원**: 단순 DQN 연산뿐만 아니라 Dueling 기능과 Double Target 로직을 가진 최신 D3QN을 지원하며, 우선도 기반 경험 재현(PER:Prioritized Experience Replay)과 유사한 하이브리드 듀얼 버퍼 등을 선택하여 효율적인 데이터 샘플링 학습을 구사할 수 있습니다.
- **H/W 가속 자동 식별**: 하드웨어 리소스를 스스로 탐지하여 CUDA(엔비디아) 및 MPS(애플 실리콘) 플랫폼에서 Pytorch 연산 가속을 최적화합니다.
- **통계 자동화 및 정량적 평가 시스템 탑재**: TensorBoard를 통한 실시간 학습 로깅을 지원함과 동시에, 학습이 종료된 모델들을 평가 스크립트(`test_agent.py`)로 일괄 검증할 수 있습니다. 각 모델은 CSV 통계를 반환하며, 내장된 분석 유틸리티를 활용해 모델 아키텍처별 비교 차트(박스 플롯)를 단번에 시각화할 수 있습니다.

## 디렉토리 구조 및 핵심 모듈
본 프로젝트는 기능 유지보수를 위하여 철저히 서브 패키지로 분할되어 있습니다.

- `train_agent.py` : 강화학습의 메인 훈련 스크립트로, 인공지능이 게임 속에서 실제로 경험을 쌓고 지능을 키우는 에피소드 전체 과정을 지휘합니다.
  - **[순환 학습 루프 (While Loop)]**: 실제 게임이 진행되는 스텝마다 다음과 같은 4단계 사이클이 실시간으로 반복됩니다.
    1. **행동 결정 (Action)**: 현재 화면을 네트워크가 평가하여 최적의 키를 누릅니다 (또는 탐험 확률에 따라 무작위 키 입력).
    2. **환경 피드백 (Step)**: 게임(환경)에 키를 전달하고, 새롭게 변한 다음 화면(상태)과 점수(보상)를 반환받습니다.
    3. **기억 저장 (Push)**: 방금 겪은 1프레임 분량의 경험 조각을 버퍼 메모리에 수집합니다.
    4. **미니배치 복습 (Train)**: 버퍼에 기억이 일정량 모이면, 예전 기억들을 무작위로 뽑아와 네트워크 가중치를 업데이트합니다.
  - **[타겟 업데이트 제어]**: 정답을 매기는 채점자인 '타겟 네트워크'를 어떻게 갱신할지에 대한 로직입니다. 수천 프레임마다 한 번에 정답지를 똑같이 복사하는 **하드 업데이트(Hard Update)**와 매 프레임마다 정답지를 아주 미세하게 현행 모델과 섞어주는 **소프트 업데이트(Soft Update)**를 하이퍼파라미터로 선택할 수 있습니다.
  - **[파라미터 감쇠 (Decay)]**: 초반에는 모험심을 발휘하여 무작위 행동을 많이 하지만 세대가 지날수록 아는 지식에만 의존하도록 조율하는 **탐험률(Epsilon) 감소** 기법과, 훈련이 성숙해질수록 섬세한 값 조정을 위해 변동폭을 서서히 줄여가는 **학습률(Learning Rate) 감소** 로직이 포함되어 안정적인 수렴을 돕습니다.
- `test_agent.py` : 학습 연산이 완전히 배제된 실전 평가 모듈. 지정 모델의 가중치를 단독 로드하여 인공지능의 확률적 탐험 기형(Epsilon-Greedy 탐색)을 끄고 순수 정책을 검증합니다. 더불어 통계 연산 및 CSV 저장 루틴이 이식되어 있습니다.
- `train_grid_search.py` : 복수 배열의 하이퍼파라미터들(DQN Type, Buffer Type 조합 등)을 지정한 범위 내에서 자동 일괄 수행시키는 파이프라인 배치 스크립트입니다.

### `/environments` (에이전트 및 환경의 상호작용 인터페이스)
- `environment.py` : 인게임 보상 체계(Reward) 설계, 행동 수행 진단, 게임 종료 판정 등 강화학습 프레임워크와의 메인 브릿지입니다.
- `vision.py` : 실시간 게임 화면 캡처 및 이미지 전처리를 수행하는 비전 코어 모듈입니다. 공룡 게임 특유의 주·야간 테마 반전에 의한 시각적 노이즈를 인공지능이 장애물로 오해하지 않도록, 물체의 외곽선만 흑백으로 추출하는 **윤곽선 검출(Canny Edge)** 기법과 시간 변위에 따른 픽셀 움직임만 감지하는 **프레임 차분(Difference)** 필터를 옵션으로 제공합니다.
- `action.py` : `pyautogui` I/O 바인딩으로 물리적인 스페이스바/방향키 입력 이벤트를 컨트롤합니다.
- `dqn.py` / `d3qn.py` : PyTorch를 근간으로 작성된 딥러닝 네트워크 아키텍처입니다. 화면의 픽셀 이미지에서 시각적 특징을 추출하고, 어떤 행동이 가장 유리할지 점수(Q-Value)를 도출합니다.
  - **[DQN (Deep Q-Network)]**: 연속된 3개의 합성곱(CNN) 층을 통과시켜 패턴을 인식한 뒤, 각 행동(점프/숙이기/대기)의 가치를 단순 계산하는 표준 신경망입니다.
  - **[D3QN (Dueling Double DQN)]**: 단순 DQN의 한계점을 극복한 진화형 모델입니다. 현재 화면의 전반적인 유리함을 평가하는 **상태 가치(Value)**와, 세 가지의 행동 핏 중에 어떤 것이 좋을지 비교하는 **행동 이득(Advantage)**이라는 2개의 흐름으로 뇌 구조를 분리(Dueling)하여 특정 행동에 편향되지 않은 정교한 판단을 내립니다.
  - **[참고] 아키텍처별 총 파라미터 수 (input_pixel=64 기준)**
    - **DQN**: 588,067 개
    - **D3QN**: 1,113,380 개

### `/trainer` (학습 버퍼 및 오프폴리시 업데이트 로직)
- `replay_buffer.py` : 에이전트가 겪은 과거의 경험(상태, 행동, 보상 결과)을 기억해 두었다가 학습에 재사용하는 메모리 공간입니다. 단일 버퍼, 듀얼 버퍼 외에 **하이브리드 버퍼(Hybrid Buffer)** 방식을 제공합니다.
  - **[하이브리드 버퍼의 특징]** 
    우선순위 경험 재현(PER) 기법을 직관적이고 가볍게 응용한 구조입니다. 인공지능이 복습(학습)을 마친 후, 자신이 예측한 값과 실제 결과 간의 오차(TD-Error)가 가장 컸던, 번역하자면 "가장 틀렸거나 배울 점이 많았던" 핵심 기억 상위 10%를 골라냅니다. 그리고 이 기억들을 우선도 전용 버퍼로 **재활용(Recycle)**하여 집중적으로 다시 복습하도록 만들어 훈련 효율을 크게 높입니다.
- `train_buffer.py` : 에이전트의 두뇌(신경망)를 직접적으로 업데이트하는 딥러닝 최적화 모듈입니다.
  - **[오차(TD-Error) 계산]**: 벨만 방정식(Bellman Equation) 원리를 사용하여, 다음 상태를 바탕으로 짐작해 본 '실제 목표 가치'와 현재 모델의 '예측 가치' 간의 차이를 계산합니다.
  - **[기울기 폭발 방지]**: 극단적인 오차로 인해 네트워크 가중치가 터져버리는 현상을 막기 위하여 `smooth_l1_loss`(Huber Loss) 함수를 적용하고, 역전파 과정에서도 `clip_grad_norm_`을 통해 기울기의 최대 한도를 안전하게 제한합니다.
  - **[타겟 네트워크 (Double DQN)]**: 에이전트가 자신의 행동 가치를 지나치게 높게 착각하는 현상(Overestimation)을 방지하기 위해, 정답을 매길 전용 채점자 역할을 하는 '타겟 네트워크'를 분리하여 운영합니다.

### `/utils` (분석, 디버깅 보조 유틸리티)
- `analysis.py` : 테스트로 축적된 CSV 기록 파일들을 읽어들입니다. 모델들의 퍼포먼스(생존 분포 지표) 차등을 박스 플롯 이미지로 렌더링하는 Pandas/Matplotlib 스크립트입니다.
- `visualize.py`, `find_monitor.py` 등 : 에이전트 작동 중 콘솔 디버깅 툴과 특정 모니터의 좌표 범위를 스크랩하는 스크립트 묶음입니다.

## 학습 진행의 흐름
### 1. 최초상태 설정, 브라우저 초기화 및 게임을 시작합니다.
- **에이전트 훈련(train_agent.py)**
  - 하이퍼파라미터 입력 혹은 기본값으로 훈련을 시작합니다. 훈련 중인 모델이 있다면 이어서 훈련합니다. 주어진 에피소드만큼 반복 훈련하며, 에피소드마다 스텝은 캐릭터 사망시까지 정해진 FPS대로 반복됩니다. 

### 2. 환경으로부터 현재 상태(게임 이미지 스택, 기준시간)을 받아 텐서로 변환하고, 신경망으로 보내 행동가치들(Q값 배열)을 받아옵니다.(with_no_grad)
- **시각(vision.py)**
  - 화면에서 게임재시작 아이콘을 찾아 좌표 및 이미지 크기를 계산합니다.
  - 해당 영역을 캡쳐하고 흑백 이미지로 변환합니다.
  - 낮/밤의 영향을 없애기 위해 윤곽선(canny) 또는 프레임 분차(difference) 전처리를 수행합니다.
  - 신경망에 보낼 이미지 크기로 리사이즈 후 게임 진행도를 알 수 있도록 4프레임의 이미지를 스택하여 반환합니다.
- **신경망(dqn.py, d3qn.py)**
  - 프레임 스택 및 시간 텐서를 받아 3층의 합성곱 연산으로 64채널로 특성을 압축합니다(no batch normalization, max pooling).
  - 전연결층(FC-layer)을 통과시켜 행동 수(3) 크기의 출력(Q값)을 생성합니다.
  - Dueling DDQN의 경우 상태가치(V)와 행동 가치(평균과의 차이값)의 합으로 Q값을 계산합니다.
    
### 3. 엡실론-그리디 정책에 따라, 랜덤 또는 가장 높은 Q값의 인덱스를 행동으로 선택합니다.
- **엡실론-그리디 정책(Epsilon-Greedy Policy)**
  - 가중치에 의한 행동 정책에 고립되어 과적합(local minimum)되지 않도록 탐험(exploration)을 하게 하는 장치입니다.
  - 랜덤 값에 따라 최적 정책에 의한 행동이 아닌 랜덤 행동을 하게 함으로써 새로운 경험을 발견하도록 합니다.
  - 에피소드가 진행됨에 따라 엡실론의 비중을 줄여 최적 정책에 의한 행동을 강화시킵니다.

### 4. 환경에 행동 인덱스를 전달하여 다음 스텝의 상태와 보상, 게임 종료 여부를 받아옵니다.
- **환경(environment.py)**
  - 행동 값에 따라 action.py의 행동을 수행합니다.
  - 프레임이 갱신되기를 기다려 다음 스텝의 상태를 파악합니다.
  - 결정된 상태와 행동에 따른 보상 및 게임 종료 여부를 반환합니다.

### 5. 이번 스텝의 경험을 메모리 버퍼에 저장합니다.
- **리플레이 버퍼(replay_buffer.py)**
  - 듀얼(우선도/노멀) 버퍼를 채택하여 보다 자극적인 경험이 선택되는 비율을 조절합니다.
  - 사망 혹은 특정 행동(점프와 숙이기)은 우선도 버퍼에 저장되고, 대기의 경우 노멀 버퍼에 저장됩니다.
  - 배치 추출 시 정해진 비율(1:1)로 각 버퍼에서 추출하여 훈련에 사용합니다.    

### 6. 정해진 배치 수 이상이 메모리에 쌓이면 랜덤하게 기억을 추출하여 신경망의 가중치를 업데이트합니다.
- **미니배치 훈련(train_buffer.py)**
  - 배치를 언패킹하고 텐서로 변환합니다.
  - 현행 모델(online model)로 최선 행동을 선택합니다.(DQN, DDQN, D3QN)
  - DDQN 이상의 아키텍쳐 사용 시 가중치가 고정된 타겟 모델(target network)이 선택된 행동을 평가합니다(벨만 방정식에 의한 타겟 정답지 계산).
  - 선택된 행동과 타겟 정답지의 오차(TD-error)를 계산하고 역전파 및 최적화를 수행합니다.
  - 미니배치 훈련 후 TD-error가 큰 상위 10%는 우선도 버퍼에 재저장됩니다(PER 단순화).

### 7. 캐릭터 사망 시 필요한 조치(타겟 모델 업데이트, 학습률 감소, 엡실론 감소 등)를 취하고 다음 에피소드로 진행합니다.

### 8. 100에피소드 경과 혹은 기존 최고 기록의 20% 이상을 달성하면 검증 루프를 실행하여 테스트 모드(epsilon=0)로 5 에피소드를 반복하고 최고점(중앙값 기준)을 경신하였을 때에는 모델을 저장합니다.

## 실행 가이드북

### 1. 패키지 동기화 및 윈도우 교정 세팅
소스코드 저장소 클론 직후, 터미널 환경에서 프로젝트 운영에 필요한 모든 모듈을 설치합니다. 
```bash
pip install -r requirements.txt
```
웹 브라우저 시스템상에 `chrome://dino/` 주소를 입력해 공룡 게임을 열어 주십시오. 게임 스크린샷 캡처 매니저는 프로젝트 디렉토리 안의 `environments/template.png` 매칭을 통해 GAME OVER 아래의 재시작 버튼을 찾아냅니다. 브라우저 창은 절대로 가려지거나 최소화되어서는 안 됩니다.

### 2. 베스트 에이전트 학습 파이프라인 가동
아래 명령어를 기입하여 지정된 하이퍼파라미터 메커니즘을 토대로 알고리즘 학습을 거행합니다.
모델 훈련 도중 이전의 최고 생존 시간을 능가하는 플레이가 발생할 경우, 실시간으로 모델의 지능(Weight Parameter)이 `models/` 디렉토리에 계속 갱신됩니다.

```bash
# dqn_type 3(Dueling), buffer_type 2(Hybrid), 1000 에피소드 동안 훈련하는 스크립트 예제
python train_agent.py --dqn_type 3 --buffer_type 2 --num_episodes 1000
```
동적 추이 분석(행동 가치 상승 폭, 페널티 반영 현황)을 위해서는 다른 터미널 인스턴스를 열고 TensorBoard 서비스를 가동하십시오.
```bash
tensorboard --logdir=runs
```

### 3. 고립 통제 환경의 실전 평가 (Test Script)
훈련을 거친 신경망이 랜덤성에 이끌리지 않고 독자적으로 얼마나 훌륭한 생존력을 보이는지 평가 파이프라인(`test_agent.py`)을 활용해 점검합니다. 
앞서 입력했던 하이퍼파라미터를 명령 인자로 입력하면 그에 맞는 저장 모델 가중치를 성공적으로 로드합니다. 에피소드 반복 진행이 끝나면 프로젝트 디렉토리 하위의 `results/` 폴더에 CSV 평가 명세서가 저장됩니다.

```bash
python test_agent.py --dqn_type 3 --buffer_type 2 --num_episodes 50
```

### 4. 평가 통계량의 자동 시각화 (Analysis Utility)
분석 도구(`utils/analysis.py`)를 가동하면 기존 확보된 모델 간의 실력 통계를 정교한 박스 플롯 그래프를 통해 가시화해 줍니다. 
내부 로직을 통해 `results/` 안의 전체 CSV 통계 기록을 색인하며, x축의 모델 이름 오버래핑을 방지하고 에피소드 편차치들을 점유율별로 비교하기 용이하게 만듭니다. 최종 비교 차트 결과물은 `results/survival_boxplot.png` 경로에 생성됩니다. 파이썬 문법을 모르는 분도 단축 인스트럭션만으로 그래프 산출이 가능합니다.

```bash
python utils/analysis.py
```
